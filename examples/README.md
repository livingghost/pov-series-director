# Examples

## `storm-watch/`

The canonical worked artifact chain for the current Skill procedure.

It begins with `source-brief.md`, produces the current Phase A preparation output, concrete media briefs, real teaching PNG files, and direct frame inspection. It then produces a separate current Phase B director package and exact submission artifacts for each target operation.

This is a canonical conforming example, not a claim that natural-language execution is deterministic. All three target branches are `not run` and contain no invented Phase C observations.

## `demo-episode.md`

A generated reading view assembled from `storm-watch/` by `scripts/build_demo.py`. Do not edit it independently.

## `field-study/`

Templates for recording real exact submissions, every returned variant, direct observations, accepted/rejected decisions, and endpoint continuity.

## `test-cases.md`

Manual/agent regression cases covering distinction usefulness, target operations, rich-direction preservation, self-contained exact text, the not-run/observed-run evidence boundary, and result-driven revision.
